# Podstr — ترجمهٔ زیرنویس با هوش مصنوعی

**زیرنویس‌ها را با هوش مصنوعی به هر زبانی ترجمه کنید.**  
افزونهٔ Chrome زیرنویس‌های پلتفرم‌های ویدیویی را شناسایی می‌کند و آن‌ها را به‌صورت زنده ترجمه می‌کند.

## Podstr چیست؟

Podstr افزونه‌ای برای Chrome است که زیرنویس‌های سایت‌های ویدیویی را دریافت می‌کند و با مدل‌های هوش مصنوعی مانند Claude، Gemini و DeepSeek (از طریق OpenRouter) ترجمه می‌کند. این افزونه با زیرنویس‌های انگلیسی، اسپانیایی، آلمانی، فنلاندی و هر زبان دیگری کار می‌کند و می‌تواند ترجمه را به هر زبان مقصدی انجام دهد.

اگر قسمت موردنظر قبلاً ترجمه شده باشد، ترجمه از حافظهٔ مشترک فوراً و رایگان بارگذاری می‌شود.

## شروع سریع

1. افزونه را از [Chrome Web Store](https://chromewebstore.google.com/detail/iophagcapjpmkcpdjkfndpdakipokeih) نصب کنید.
2. ویدیویی دارای زیرنویس را باز کنید، زبان را انتخاب کنید و تمام.

برای ترجمهٔ محتوای جدید به [کلید API سرویس OpenRouter](https://openrouter.ai/keys) نیاز دارید؛ کلیدهای رایگان نیز در دسترس هستند.

## پلتفرم‌های پشتیبانی‌شده

| پلتفرم | زیرنویس | وضعیت |
|----------|-----------|--------|
| **YouTube** | Manual CC (not auto-generated) — primary `/api/timedtext` + transcript-panel fallback | آزمایش‌شده |
| **Netflix** | TTML via Cadmium player API | آزمایش‌شده |
| **HBO Max** | WebVTT via DASH manifest | آزمایش‌شده |
| **BBC iPlayer** | TTML/EBU-TT-D | آزمایش‌شده |
| **RaiPlay** | SRT via MAIN-world fetch interceptor | آزمایش‌شده |
| **kino.pub** | HLS subtitles (Vidstack player) | آزمایش‌شده |
| **RTS Planeta** | Native HTML5 `<track>` | آزمایش‌شده |
| **ARTE** | HLS subtitles | آزمایش‌شده |
| **Plex** | HLS subtitles | آزمایش‌شده |
| **Filmzie** | HLS subtitles | آزمایش‌شده |

ممکن است سایت‌های دیگری که از زیرنویس‌های HLS، VTT، TTML یا `<track>` بومی استفاده می‌کنند نیز کار کنند؛ در popup افزونه روی **Enable** کلیک کنید.

## امکانات

- **هر زبانی** — ترجمه از هر زبان زیرنویس به هر زبان مقصد
- **چندین مدل هوش مصنوعی** — انتخاب مدل بر اساس کیفیت و هزینه، همراه با مدل‌های رایگان
- **هزینهٔ ترجمه** — مشاهدهٔ هزینهٔ هر ترجمه روی ویدیو
- **حافظهٔ مشترک** — یک نفر ترجمه می‌کند و دیگران رایگان استفاده می‌کنند
- **حافظهٔ محلی هوشمند** — بارگذاری فوری ترجمه‌های قبلی
- **تنظیم زمان‌بندی** — کلیدهای `[` و `]` برای جابه‌جایی ±۰٫۵ ثانیه
- **شخصی‌سازی ظاهر** — فونت، رنگ، شفافیت و موقعیت
- **میانبرهای صفحه‌کلید** — کلید `B` برای جابه‌جایی موقعیت و `\` برای بازنشانی
- **۱۴ زبان رابط کاربری** — EN، RU، UK، BE، SR، ES، FR، DE، PT، ZH، JA، KO، TR، FA

## سازوکار کار

1. **شناسایی** — service worker درخواست‌های زیرنویس را با `chrome.webRequest` دریافت می‌کند.
2. **دریافت** — اسکریپت پس‌زمینه فایل‌های زیرنویس را بدون محدودیت CORS دانلود می‌کند.
3. **ترجمه** — ترجمه به‌صورت دسته‌ای با OpenRouter API انجام می‌شود؛ مدل و کلید را شما انتخاب می‌کنید.
4. **حافظه** — VTT ترجمه‌شده با gzip فشرده و در حافظهٔ محلی و مشترک ذخیره می‌شود.
5. **نمایش** — content script زیرنویس را هم‌زمان با پخش ویدیو نشان می‌دهد.

## پرسش‌های متداول

**آیا به کلید API نیاز دارم؟** اگر قسمت موردنظر در حافظهٔ مشترک باشد، نه. برای ترجمهٔ جدید به کلید OpenRouter نیاز دارید.

**آیا افزونه رایگان است؟** خود افزونه رایگان است و ترجمه‌های موجود در حافظهٔ مشترک نیز رایگان هستند. فقط برای ترجمهٔ محتوای جدید هزینهٔ سرویس هوش مصنوعی را می‌پردازید.

**کیفیت ترجمه چگونه است؟** به مدل انتخابی بستگی دارد. Claude Opus از نظر کیفیت با زیرنویس‌های هواداری خوب برابری می‌کند. DeepSeek و Gemini Flash ارزان‌تر هستند و همچنان خوانایی خوبی دارند.

**هزینهٔ معمول چقدر است؟** بسته به مدل، برای هر قسمت حدود ۰٫۰۰۵ تا ۰٫۰۵ دلار است. مدل‌های رایگان نیز وجود دارند.

## حریم خصوصی

- کلید API شما روی دستگاهتان می‌ماند و هرگز به سرور ارسال نمی‌شود.
- هیچ ردیابی، تحلیل آماری یا تبلیغاتی انجام نمی‌شود.
- متن زیرنویس فقط برای سرویس هوش مصنوعی انتخابی شما ارسال می‌شود.
